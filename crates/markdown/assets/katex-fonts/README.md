# KaTeX fonts

Unmodified copies of the KaTeX font files used by RaTeX's `standalone` SVG
output. Sourced from the RaTeX repository at tag `v0.1.14`
(https://github.com/erweixin/RaTeX), which distributes them from the KaTeX
project (https://github.com/KaTeX/katex).

These fonts are licensed under the SIL Open Font License, Version 1.1
(https://openfontlicense.org). The per-font copyright and license notices are
embedded in each font's name table; they must be preserved when redistributing
the fonts or derivatives.
